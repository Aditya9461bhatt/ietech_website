## How this works

This post is a plain file in `content/blogs/`. It only appears on the live
website after you press **Publish to Live** in the CMS — saving alone never
changes the internet.

- Set **Status** to *Published* to include it on the site
- Use the image button in the toolbar to add pictures inline
- Delete this sample whenever you like
